Appshell — Governed Desktop Workspace

How it works

From development to release in minutes, with zero host liability.

  1. 1

    Build & Scaffold

    appshell create scaffolds an app with a sandboxed UI, isolated backend and dashboard widget. appshell dev launches the live development shell.

  2. 2

    Release by Tag

    Push a git tag like v1.2.0. CI builds verified packages, computes SHA-256 digests, and publishes directly to the catalog release feed.

  3. 3

    Install with Consent

    Users click Install in the web store or shell. The host prompts for user confirmation, verifies integrity, checks manifest permissions, and runs the app isolated.

Install from web store, confirm in the shell

The store's Install button uses a secure deep link (appshellcatalog://) to hand off to the desktop client. The host displays provenance, permissions, and origin, downloading nothing until the user explicitly consents.

Automatic updates and instant zero-download rollbacks are managed right on the dashboard.

Consent Gate — Verified App Installation

Secure by design

Third-party code is adversarial. Core apps get no exemption.

  • Every app isolated

    Sandboxed WebContentsView on origin app://<id>/ with its own session partition. Zero Node access, zero cross-app fetches.

  • Verified packages

    Packages are strictly checked against catalog SHA-256 hashes, restricted to allowed sources, and stripped of symlinks.

  • Declared capabilities

    Network destinations, secrets, notifications and identity must be pre-declared in manifest.json and enforced on every single IPC call.

  • Identity, not credentials

    Apps receive 5-minute Ed25519 JSON Web Tokens signed by the host and scoped to their application ID alone. No credentials ever leak.

  • Widgets as pure data

    Dashboard widgets are plain JSON descriptors. The host shell renders them using native components—no third-party code runs on the dashboard.

  • Tested against hostile apps

    Every commit runs a suite testing 21 distinct sandbox evasion vectors across Windows, macOS, and Linux runners.

Build your first app

Scaffold a fully isolated mini-app in 10 seconds. Includes UI, Node backend, widgets, and typed SDK bindings.

pnpm appshell create ../my-app --id my-app
pnpm appshell dev ../my-app
pnpm appshell package ../my-app

The SDK exposes storage, secrets, notifications, widgets, identity, and the utility backend.

Make it your product

One configuration file defines branding, deep-link protocols, and security policy.

{
  "name": "Appshell",
  "protocol": "appshell",
  "package": { "extension": ".appshell", "displayName": "Appshell App" },
  "catalog": "https://samuelek25k.github.io/appshell-apps/index.json",
  "policy": { 
    "capabilities": "enforce", 
    "allowedSources": ["https://github.com/samuelek25k/"] 
  }
}
