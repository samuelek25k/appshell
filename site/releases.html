Verify Package Integrity

Every binary release is published with a cryptographically verifiable SHA-256 checksum.

SHA-256 Verified

To verify your downloaded installer matches the official release build, open your terminal and run:

# Windows PowerShell:
Get-FileHash .\Appshell-Setup.exe -Algorithm SHA256
# macOS Terminal:
shasum -a 256 Appshell-arm64.dmg
# Linux:
sha256sum Appshell.AppImage

Compare the computed hash against the checksum published in the corresponding GitHub Release release assets.

Zero-Trust Multi-Process Shell

Untrusted apps run in isolated Electron renderer contexts with Node integration disabled. Communication occurs strictly over typed IPC channels with capability allowlists.

Deep-Link App Store Installs

Browse apps on the web store and install them with one click via appshellcatalog://. The shell halts and asks for explicit confirmation before downloading.

Developer CLI Toolchain

Use appshell create, appshell dev, and appshell package to build, test in hot-reloading dev hosts, and bundle production tarballs.

Build from Source & Package Local Installers

You can build, test, and package Appshell desktop installers locally on Windows, macOS, or Linux using Node 22 and pnpm: 

# 1. Clone repository
git clone https://github.com/samuelek25k/appshell.git
cd appshell

# 2. Install dependencies & verify tests
pnpm install
pnpm check && pnpm test

# 3. Launch the desktop shell in development
pnpm start

# 4. Package standalone installers for your platform
pnpm dist:win      # Windows NSIS installer (.exe)
pnpm dist:mac      # macOS DMG (.dmg) and Zip (.zip)
pnpm dist:linux    # Linux AppImage (.AppImage) and Debian (.deb)
pnpm dist          # Package all target installers
